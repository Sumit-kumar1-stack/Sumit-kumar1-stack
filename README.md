## 🧩 Engineering Areas I Care About

```text
Secure Authentication & Authorization
            ↓
Tenant / Resource Isolation
            ↓
Clean Domain & API Boundaries
            ↓
Queues + Background Processing
            ↓
Provider Abstraction
            ↓
Reliable Data & Transactions
            ↓
Testing + Observability
            ↓
Production-Oriented Deployment
```

I especially enjoy designing systems where **business rules are enforced on the backend**, external providers can be swapped behind clean interfaces, and asynchronous work is handled through durable queues instead of tightly coupling everything to a web request.
